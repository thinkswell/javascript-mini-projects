
# Text Statistics

Text Statistics is a simple web application that analyzes text and displays useful statistics in real time.

## Features

- Word count
- Total character count
- Character count without spaces
- Sentence count
- Paragraph count
- Estimated reading time
- Clear text button
- Real-time updates while typing

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the TextStatistics folder.
3. Open the index.html file in a web browser.
4. Enter text in the text area to see the statistics.

No additional libraries or installations are required.
