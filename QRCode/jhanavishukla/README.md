QR Code Generator
A simple and responsive QR Code Generator built using HTML, CSS, and JavaScript. The project allows users to generate QR codes dynamically from user input.
✨ Features
- Generate QR codes from user input
- Simple and intuitive interface
- Responsive design
- Interactive JavaScript functionality
- No backend required
🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
🚀 Getting Started
Open qrcode.html in your browser.
You can also use the Live Server extension in VS Code.
